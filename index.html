INSTALLATION

How to get started

Close Among Us before changing its files.

  1. Windows: Download Polus.exe (v1.1.0) and run it directly.
  2. Use Detect Steam, or Browse to select the folder containing Among Us.exe.
  3. Choose Setup loader to install the required BepInEx IL2CPP files, then choose Install Polus.
  4. Launch Among Us and check the BepInEx log if anything fails to load.
  5. Android: Download and install the Polus Android APK (v1.1.0), open the patcher, and follow its on-screen instructions.
Android installation note: the patched APK may be signed differently from the Play Store version. Replacing the original game can require uninstalling it first, which may erase local game data. Back up anything important before proceeding. iOS: not supported.
