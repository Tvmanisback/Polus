INSTALLATION

How to get started

Close Among Us before changing its files.

  1. Windows: Download Polus.exe (v1.1.0) and run it directly.
  2. Use Detect Steam, or Browse to select the folder containing Among Us.exe.
  3. Choose Setup loader to install the required BepInEx IL2CPP files, then choose Install Polus.
  4. Launch Among Us and check the BepInEx log if anything fails to load.
  5. Android: Download and install the Polus Android APK (v1.1.0), open the patcher, and follow its on-screen instructions.
  6. iOS: Download regionInfo.json. A website can host and download the region file, but iPadOS does not let ordinary JavaScript write directly into Among Us's private app files. You must import the file using a method supported by your Among Us installation.
Important: the region file points to the Polus server at polus.yapyur.org:25906. The region file alone does not install itself into Among Us; it must be imported by the game or a supported iOS installation workflow.
